# CUDA-matched torch build. Install this BEFORE requirements.txt, and only on a
# machine whose NVIDIA driver is CUDA 12.x (check `nvidia-smi`):
#
#   pip install -r requirements-gpu.txt
#
# Skip it on CPU-only machines and on Colab, where the default PyPI wheel is
# already correct; requirements.txt alone is enough there.
#
# Why this file exists: pip install torch pulls the newest-CUDA-major wheel from
# PyPI, which on an older driver leaves torch.cuda.is_available() == False with
# nothing but a UserWarning. Always assert it is True after building an env.
#
# If your driver is a different CUDA version, swap cu126 for the matching tag
# (see https://pytorch.org) — and do NOT pip-uninstall the leftover nvidia-*
# wheels of the wrong CUDA major afterwards: the two sets share paths under
# site-packages/nvidia/, so removing one deletes shared libraries (libcudnn.so.9)
# out from under the one you kept. Build a fresh env instead.

--index-url https://download.pytorch.org/whl/cu126
torch==2.7.1+cu126
